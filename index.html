Rules of the Arena

Three pillars: no AI, built from scratch, and a viva. Everything else follows from these.

Banned: AI chat assistants, AI code completion or agents in your editor or terminal, AI-generated test cases or locators, AI browser extensions, and AI summaries in search results (switch them off). Allowed: official documentation, books, videos and courses, and normal search results or community answers to understand a concept. You type every line yourself. If you adapt a non-trivial snippet from the web, link its source in a code comment.

Start from an empty public repository. Installing libraries and frameworks (Selenium, Playwright, Cypress, NUnit, RestSharp and so on) is fine. Starter kits, boilerplates, scaffolding generators that create sample tests, and copied framework architectures are not.

Your commit history is part of the review. Make small commits with meaningful messages across the month. One giant commit near the deadline counts against you.

Keep a LEARNINGS.md in your repository. Three to five lines each week: what you built, what broke, what you learned. It helps you in the viva and it is the point of the contest.

Every player has an individual interview after the freeze. If you cannot explain it, it does not count: any part of your project that you cannot explain earns no points for that part.

You can discuss concepts and help each other understand. You must never share, show or read another player's code before results are announced. Copying means instant disqualification.

The demo site is shared and resets often. Use unique test data (append a timestamp or random suffix). Do not change shared core configuration.

No hardcoded sleeps. Use proper waits. Keep configuration out of test code. Your repository must be public by the code freeze so the scorer can run it.

At the start of your viva you state, on record, that you wrote everything yourself without AI. If this is later found to be false, you are disqualified and removed from the leaderboard.

Keep it friendly. The organizer's decision on edge cases is final.
