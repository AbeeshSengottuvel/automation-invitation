Rules of the Arena

Any tool or language is allowed. One public repository per player. It must be public by the submission deadline so the GitHub Actions scorer can run it.

The demo site is shared and resets frequently. Use unique test data (e.g., append timestamps) to avoid conflicts. Do not edit core shared configurations.

No hardcoded sleeps. Use dynamic waits. No copying other players' work (instant disqualification).

Keep it friendly. Organizer decisions on edge cases are final.
